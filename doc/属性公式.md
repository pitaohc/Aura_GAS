
# 一、核心原则与简化
1.  **所有次级属性 = 基础值 + Σ(初级属性 * 系数)**。
2.  **伤害计算 = 基础伤害 * 增伤倍率 - 固定减伤**。
3.  **概率属性 = 基础概率 + Σ(初级属性 * 系数)**，并设置**硬上限（如100%）**。

# 二、基础值与转化公式（完全线性化）

| 次级属性 | 公式 | 说明 |
| :--- | :--- | :--- |
| **生命上限** | `100 + (Vig - 10) * 10` | 线性，每点活力+10血。 |
| **生命回复/秒** | `1 + (Vig - 10) * 0.1` | 线性，每点活力+0.1回复。 |
| **法力上限** | `100 + (Int - 10) * 5` | 线性，每点智力+5法力。 |
| **法力回复/秒** | `1 + (Int - 10) * 0.2` | 线性，每点智力+0.2回复。 |
| **护甲值** | `10 + (Res - 10) * 2` | 线性，每点韧性+2护甲。 |
| **护甲穿透** | `10 + (Res - 10) * 1` | 线性，每点韧性+1穿透。 |
| **格挡几率 %** | `5 + Armor * 0.02` | **注意：这里是属性(Armor)驱动概率，仍为线性**。上限100%。 |
| **暴击几率 %** | `5 + ArmorPenetration * 0.1` | **属性(ArmorPenetration)驱动概率**。上限100%。 |
| **暴击伤害 %** | `50 + Int * 0.5` | **注意：这里将暴击伤害与智力关联**，每点智力+0.5%暴伤。这是为了简化，避免多个属性同时影响暴击。 |
| **暴击抵抗 %** | `5 + Armor * 0.02` | **属性(Armor)驱动概率**。上限100%。与格挡共用护甲值作为来源。 |

# 三、战斗计算公式（完全线性化）

## 1. 伤害计算（以物理为例）
```
最终伤害 = 基础伤害 * (1 + (Str - 10)/100) * (1 + 暴击伤害加成) - 有效固定减伤
```
**其中：**
*   **有效固定减伤** = `Max(0, 目标护甲 - 攻击者护甲穿透)`
    *   *这是唯一保留的“条件判断”，但它只决定一个值是否为0，不影响公式本身的线性本质。在属性系统中，这通常通过在计算流程中编写一个简单的取最大值函数来实现，而不是作为一个持久化的属性。*

## 2. 概率触发
*   **暴击触发**：`if 随机数(0,100) < 暴击几率 then 应用暴击伤害`
*   **格挡触发**：`if 随机数(0,100) < 格挡几率 then 本次伤害 = 本次伤害 * 0.5`
*   **暴击抵抗生效**：`if 攻击者暴击成功 then 检查目标暴击抵抗，一定概率使暴击降级为普通攻击`

# 四、职业模板示例（100级，共495点属性）

## **1. 铁壁战士（主Vig/Res）**
*   **加点**：Vig 210， Res 210， Str 85
*   **衍生属性**：
    *   `Max Health = 100 + (210-10)*10 = 2100`
    *   `Armor = 10 + (210-10)*2 = 410`
    *   `Armor Penetration = 10 + (210-10)*1 = 210`
    *   `Block Chance = 5 + 410*0.02 = 13.2%`
    *   `Crit Chance = 5 + 210*0.1 = 26%`
    *   `Damage Multiplier = 1 + (85-10)/100 = 1.75`
*   **角色定位**：超高血量、高固定护甲、高固定穿透、中等增伤。**减伤模型从百分比变为固定值**，使其在面对低伤害、高频率攻击时极强，但面对单次超高伤害（如Boss大招）时，固定减伤的价值会下降。

## **2. 元素法师（主Int）**
*   **加点**：Int 250， Vig 150， Res 105
*   **衍生属性**：
    *   `Max Mana = 100 + (250-10)*5 = 1300`
    *   `Crit Chance = 5 + (10+95*1)*0.1 = 15% (基于105点韧性)`
    *   `Crit Damage = 50 + 250*0.5 = 175%` (极高暴伤)
    *   `Damage Multiplier = 1 + (250-10)/100 = 3.4`
    *   `Max Health = 100 + (150-10)*10 = 1500`
    *   `Armor = 10 + (105-10)*2 = 200`
*   **角色定位**：极高伤害倍率和极高的暴击伤害，但暴击率较低。需要依赖装备或技能提升暴击率。血量适中，护甲低（固定减伤值低），是典型的“玻璃大炮”。

# 五、此简化方案的优缺点

*   **优点**：
    1.  **技术实现极其简单**：所有数值都可通过属性系统直接提供和叠加，无需在伤害计算代码中编写复杂的数学公式。
    2.  **完全数据驱动**：平衡性调整只需修改属性转化系数和基础值。
    3.  **性能优异**：计算逻辑简单，无复杂运算。

*   **缺点与妥协**：
    1.  **“固定减伤”模型改变游戏体验**：护甲不再是百分比减伤，游戏后期面对极高基础伤害时，固定减伤的价值会迅速下降，可能需要引入“护甲转化为百分比减伤”的额外属性来修正。
    2.  **属性联动被削弱**：例如“韧性同时影响护甲和穿透”这个巧妙设计，在固定减伤模型下，高韧性意味着同时拥有高防和高破，可能导致数值膨胀。
    3.  **概率上限难以用纯属性实现**：超过100%的概率属性没有意义。需要在应用层或通过设置属性软上限来处理。

**结论**：完全使用基础属性驱动数值，**可以**实现一个功能完整但战斗模型简化的RPG系统。它适合快速原型、移动端游戏或强调数值成长的游戏。如果需要更深层次的策略交互和百分比减伤的战术深度，则必须引入“效果修饰器”或“计算函数”等额外机制。
